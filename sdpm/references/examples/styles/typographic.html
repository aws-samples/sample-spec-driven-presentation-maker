TYPE DECIDES
Design decision: immediate recognition comes from typography alone; every non-type mark competes with the message.
Limits: cover ≤ 3 words; title = 1 line; at most 1 red word; body = 1 block of ≤ 3 lines; a display word never shrinks to fit — a word wider than the content width (about 8 characters at --fs-display) is broken into two lines or bleeds past the right edge on purpose.
Use 0 shapes, 0 rules, 0 boxes, 0 images except charts, 0 emoji, and 0° rotation; muted grey is the only second colour.
KEEP IT TIGHT
DO: make one claim per slide, make the title that claim, keep margins ≥ 5%, keep contrast ≥ 4.5:1 (≥ 3:1 for 18pt+), and label chart values directly.
DON'T: add decoration, extra colours, emoji, body fragments, or empty gridlines; only the headline may bleed past the right edge as a deliberate exception.
Renderer fact: slide JSON has no letter-spacing; create tightness with size and line breaks, using only 800 or 900 weight for display type.
ONE BEAT
The title is a single word or a phrase of ≤ 3 words.
It carries one claim, not a topic label.
Supporting copy remains one block of ≤ 3 lines.
8–18 SLIDES
Sequence one visual beat per slide; alternate very large statements with quieter evidence while retaining the same frame.
Break a word across lines only when the whole word cannot stay legible at display size or when the break reveals a meaningful spoken beat.
Use no fixed chapter shape: pacing comes from scale, white space, and deliberate repetition rather than a purpose-specific outline.
