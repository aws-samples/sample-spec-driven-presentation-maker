Large-room speaking system
keynote
One beat. Two seconds. Readable from the back row.
Design decision
The speaker is the medium; each slide is one beat of support.
One short claim
Use 12 words or fewer. Meaning lands before attention returns to the speaker.
Text is the slide
The title is the claim. Add only one subtitle when spoken context is insufficient.
28pt is the floor
If a label needs smaller type, remove detail or split the content across slides.
One claim; minimal color; ≥ 5% margins; direct chart labels; no decorative gridlines; no emoji.
Renderer facts
Preserve the restraint when HTML refinements disappear.
Native tables
Tables inherit the template font. Do not set per-table font-family; use aligned rows only when needed.
Filled shapes
Template shadows may carry through. Set every filled shape shadow off explicitly.
Type mapping
Slide JSON omits tracking and line height. Use bold for 650; set box heights explicitly.
Text contrast ≥ 4.5:1, or ≥ 3:1 at 18pt and above.
Message grammar
Write the conclusion, not the topic.

Split metrics
