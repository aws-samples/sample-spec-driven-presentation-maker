Decision document style
Lead with the conclusion; prove it with evidence.
For senior readers who decide alone and discuss together. Assertion titles preserve the argument when only titles are scanned.
CONSULTING / LIGHT / DECISION-FIRST
Senior readers must reach the decision even when they scan only the title rows.
Read alone and projected: verbal clarity and room-scale hierarchy outrank decoration.
Do
  • Make one full-sentence claim the title — title-only scanning must preserve the argument; use no more than two lines.
  • Keep at least 5% margins and 4.5:1 contrast — use 3:1 only for type at 18pt and above.
  • Label values directly and remove empty gridlines — readers should not decode visual scaffolding.
  • Use navy for structure and blue for one takeaway.
Do not
  • Do not use topic labels or decorative imagery — neither advances the decision.
  • Do not use gradients, shadows, or rounded corners — set shape shadows off explicitly.
  • Do not add a second accent or a redundant legend — preserve one unambiguous takeaway.
  • Do not use emoji — inconsistent glyph support is not renderer-safe.
Use navy for structure and blue only for the single takeaway.

Renderer constraints preserve hierarchy in editable slide JSON.
Treat these as build rules, not optional visual refinements.
Native tables
Native tables inherit the template font and accept no per-table font-family. This style accepts the template font; use aligned text rows only when a special face is essential.
Filled shapes
Filled shapes may inherit a template shadow. Set every filled shape's shadow off explicitly (`"_noEffects": true` on the element); this style never uses shadows.
HTML-only type refinements
Slide JSON has no letter-spacing, line-height, or intermediate font weights such as 650. Approximate spacing with explicit box heights and approximate weight with bold; use the token size unchanged.

A 20-minute decision deck needs 10–14 claims from answer to action.
Target 20–55 visible words per slide; use 55–90 only on a deliberate text-heavy bottom-line page.
Title grammar that works
  • “The preferred option pays back within two cycles.” — complete claim with an implication.
  • “Three drivers explain most of the gap.” — quantified assertion that previews evidence.
Title grammar that fails
  • “Market overview” — names a topic but withholds the conclusion.
  • “What should we do next?” — asks the reader to supply the answer.
Sentence construction
Use subject + active verb + implication. Keep one assertion to two lines maximum. Put qualifiers in the grey lead-in rather than weakening the title.
Narrative test
Read titles alone in sequence. They must form a defensible argument with no missing “so what” and no repeated claim.
Lead with the answer; use the remaining slides to prove it.

Usage rules
  • Navy: assertion titles, labels, axes, and totals.
  • Muted grey: lead-ins, units, footnotes, and sources.
  • Surface and border greys: quiet groups and hairlines only.
  • Electric blue: one bar, total, tracker item, or takeaway rule.

Standard frame
Title and content geometry
Title box: 192 px (two lines), x=120, y=60, width=1680. One-line titles leave the second line empty; content never moves up. Lead-in: y=270, height=60. Rule: y=345. Content: y=375–900.
Template footer contract
Source line is content (draw it); page number is the template's (do not draw it). Keep the bottom-right band x=1400–1800, y=985–1080 clear for the template page number.
The title zone never moves; only evidence geometry changes.
