PART 2 / RULES
One signal controls the page
Readers scan at distance; one decisive signal must outrank every supporting detail.
DO / PRESERVE THE WARNING HIERARCHY
  • Keep one claim per slide; the title is that claim.
  • Set uppercase headlines in 1–5 words and at most 2 lines.
  • Allow one yellow filled panel per slide; otherwise use yellow only for text, rules, or outlines.
  • Use one 10px stripe on the top edge only.
  • Let one numeral at 56–96pt become the largest element.
  • Keep all content inside margins of at least 5%.
  • Maintain contrast of at least 4.5:1, or 3:1 for type at least 18pt.
DO NOT / REMOVE COMPETING MOTION
  • Use 0° rotation and no tilted text or panels.
  • Use 0 italic words; all display type stays upright.
  • Use 0 gradients except the hazard stripe.
  • Use no colour beyond black, white, neutrals, and safety yellow.
  • Use 0 emoji; source icons through the asset library when needed.
  • Label chart values directly and keep 0 gridlines that carry no information.
  • Do not add a bottom stripe when the top stripe is present.
NUMERIC LIMITS / YELLOW FILLS ≤ 1 / STRIPES = 1 × 10PX / TITLE ≤ 2 LINES / ROTATION = 0° / ITALICS = 0
