Rules / read first
One signal controls the page
One decisive signal outranks supporting detail.
Do / preserve the warning hierarchy
  • Keep one claim per slide; the title is that claim.
  • Use uppercase headlines in 1–5 words and at most 2 lines.
  • Allow one yellow filled panel; otherwise yellow is text, rules, or outlines.
  • Use one 10px stripe on the top edge only.
  • Let one 56–96pt numeral become largest.
  • Keep content inside margins of at least 5%.
  • Maintain contrast ≥4.5:1, or ≥3:1 at 18pt+.
Do not / remove competing motion
  • Use 0° rotation; never tilt text or panels.
  • Use 0 italics; display type stays upright.
  • Use 0 gradients except the hazard stripe.
  • Use no colour beyond black, white, neutrals, and safety yellow.
  • Use 0 emoji; source needed icons through the asset library.
  • Label chart values directly; keep 0 uninformative gridlines.
  • Never add a bottom stripe when the top stripe is present.
