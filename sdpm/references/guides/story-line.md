# Story Line

A deck's slides are a sequence, and the sequence is what persuades. Decide the line the
story takes before writing the outline: it fixes what the first slide is for, what the
last one leaves behind, and which slides are allowed to exist in between.

Pick one backbone for the whole deck. Then shape individual slides inside it with the
vocabulary further down.

## Pick one backbone

Each family answers a different question about the audience. Read the condition first and
let it choose — the frameworks named inside a family are variations on the same move, so
the family matters more than which name you pick from it.

### Conclusion-First

**When**: the audience already has the context, or has no time. Executives and
decision-makers expect this; burying the conclusion loses them before you reach it.

**Shape**: lead with the recommendation, then justify it.

**Frameworks**: minto-pyramid (SCQA: situation → complication → question → answer),
SCR (situation → complication → resolution), answer-first / top-down.

### Persuasion Sequence

**When**: the audience does not yet feel the urgency. Offering the answer first would
make it sound like a solution to a problem nobody has.

**Shape**: build the need, then satisfy it. The gap between "this is broken" and "here is
how to fix it" is what creates the momentum.

**Frameworks**: monroe-motivated-sequence (attention → need → satisfaction →
visualization → action), AIDA (attention → interest → desire → action), problem-solution
(problem → amplification → solution → evidence → path).

### Contrast / Vision

**When**: the audience needs to see a future worth moving toward, and the present is not
painful enough on its own to move them.

**Shape**: alternate between current pain and possible gain. The oscillation builds the
desire for change.

**Frameworks**: what-is/what-could-be (Duarte), before-after-bridge, gap-analysis.

### Narrative Arc

**When**: the audience needs to feel the journey rather than hear the conclusion, and
your credibility comes from having been through the struggle.

**Shape**: transformation over time — a situation, a turn, a different situation.

**Frameworks**: hero's-journey (business), failure-lesson-success,
challenge-choice-consequence, kishōtenketsu, fichtean-curve, story-circle.

### Logical Grouping

**When**: the content is broad or many-sided and no single thread runs through it, so the
audience's problem is orientation rather than persuasion.

**Shape**: group by theme, time or impact, and give the audience the map first. Nested
loops keep several threads alive without losing cohesion.

**Frameworks**: by-topic, chronological, highlight-top-N, nested-loops, frame-story.

## Shape the slides inside it

The backbone decides the order. These decide what a single slide does.

### Narrative Technique

**Duarte framework**: sparkline, new-bliss.
S.T.A.R. moment: memorable-dramatization, repeatable-sound-bite, evocative-visual,
shocking-statistic, emotive-storytelling.

**Persuasion mode**: kairos, social-proof, authority-appeal, scarcity.

### Rhetorical Device

**Repetition**: anaphora, epistrophe, anadiplosis, diacope, symploce.

**Structure**: tricolon, climax/auxesis, antithesis, chiasmus.

**Rhythm**: asyndeton, polysyndeton, isocolon.

**Imagery**: hyperbole, litotes, synecdoche, metonymy.

### Slide Technique

**Opening**: cold-open, hook-question, startling-statistic, provocative-statement,
"imagine…" scenario.

**Pacing**: progressive-disclosure, build-slide, pattern-interrupt, pregnant-pause,
callback, bookend, cliffhanger.

**Closing**: circular-close, memorable-last-line, Q&A-bridge.

### Data Storytelling

**Framing**: data-ink-ratio, chartjunk, small-multiples.

**Narrative with data**: lead-with-insight, build-the-case, trend-then-anomaly,
zoom-in-zoom-out.

**Emotional data**: humanize-the-number, anchor-to-familiar, unit-chart/isotype.
